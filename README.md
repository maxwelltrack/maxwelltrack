MaxwellTrack IoT Cloud is an operated platform for teams that run real equipment: pumps,
meters, generators, cold rooms, vehicle fleets and remote sites. Devices report to the
cloud; people watch, control and automate them from one console, and pay only for what
they use.

### What the platform does

| | |
| --- | --- |
| **Monitor and control** | Live dashboards, history, and controls that reach the device in real time |
| **Automate** | Flows that react to readings, schedules and device status, control other devices and alert your team by email or chat |
| **Sites and alarms** | Process diagrams, prioritised alarms with shelving, protected controls and an audit journal |
| **Remote updates** | Firmware updates over WiFi and cellular, with delivery tracked to the device |
| **Fleets and insurance** | Vehicle tracking, driver behaviour, and usage-based insurance with owner consent |
| **Serve your customers** | Share devices with your own customers under your brand, with usage per customer |
| **MaxwellTrack AI** | An assistant that answers questions about your devices and acts on them on request |

### Get started

1. [Create an account](https://maxwelltrack.com/register) and add a device in the console.
2. Install the **MaxwellTrack** library and flash the example with your device ID and token, or write and deploy code in the browser with the MCode IDE.
3. Follow the [quickstart](https://maxwelltrack.com/docs) to see live readings in about ten minutes.
